# Gelybo

Game nuôi thú cozy trên web: Gelybo là một sinh vật gel pha lê trong suốt, thân là quả cầu lăn, đầu viên sỏi nổi phía trên nối bằng từ trường, trong bụng ôm một lõi phát sáng. Gelybo sống trên **Moonbell Observatory**, một đài thiên văn trên mặt trăng.

Dự án học tập, phi thương mại.

## Chơi thử

Mở `index.html` trong trình duyệt, hoặc qua GitHub Pages của repo này.

- Kéo để xoay camera, chụm hai ngón hoặc lăn chuột để phóng to thu nhỏ.
- Chạm mặt trăng để Gelybo lăn tới. Chạm đầu, chạm thân để chọc.
- Khay dưới: chọn lõi ngũ hành (Kim, Mộc, Thủy, Hỏa, Thổ) và phụ kiện hoàng đạo.
- Nút góc phải: ngày/đêm, đồ hoạ HD/Nhẹ.

## Tài liệu

- [DESIGN.md](DESIGN.md): toàn bộ thiết kế đã chốt (nhân vật, lõi, phụ kiện, thế giới, kỹ thuật). Đọc file này trước khi sửa bất cứ thứ gì.
- [ROADMAP.md](ROADMAP.md): việc đang làm, việc tiếp theo, lỗi đã biết.
- `concepts/`: ảnh concept tham chiếu.

## Kỹ thuật
